# Требования к рабочей среде

Этот документ определяет минимальные требования для подготовки локальной рабочей области и запуска bootstrap-скриптов.

## Поддерживаемые системы

- Windows 10 или Windows 11 — используется `scripts/bootstrap-workspace-windows.ps1`.
- Linux с Bash — используется `scripts/bootstrap-workspace-linux.sh`.

## Обязательные инструменты

| Среда   | Инструмент | Назначение                                        |
| ------- | ---------- | ------------------------------------------------- |
| Все ОС  | Git        | Клонирование и работа с репозиториями             |
| Linux   | `jq`       | Чтение `config/repositories.json` Linux-скриптом  |

Проверьте доступность инструментов перед началом работы.
В Windows PowerShell:
```powershell
git --version
```

В Linux:
```bash
git --version
jq --version
```
## Доступ к GitHub

Для работы необходимы:
- аккаунт GitHub;
- доступ к организации Miluino и назначенной команде;
- сетевой доступ к `github.com`;
- настроенные имя и e-mail Git для создания коммитов.

Проверить настройки Git можно командой:
```powershell
git config --global --get user.name
git config --global --get user.email
```
## Рабочая область

Разработчик должен иметь:
- права на создание каталогов и запись в выбранный `WorkspaceRoot`;
- достаточно свободного места для репозиториев своей команды;
- отсутствие конфликтующих каталогов по путям из `config/repositories.json`.
## Ограничения

- Разработчик не изменяет `dev-guidelines`, `config/repositories.json` и bootstrap-скрипты без явного поручения администратора.
- Новые репозитории и команды в организации создаёт администратор.
- Требования конкретного проекта — компилятор, SDK, IDE и инструменты сборки — описываются в документации соответствующего репозитория.
